# 제1당 소리

## 배경음악 (운영자가 고름)

아래 이름으로 `public/jeildang/audio/`에 넣으면 그 화면에서 자동으로 재생된다. 없는 파일은 조용히 건너뛴다.

| 파일 | 나오는 곳 | 반복 |
|---|---|---|
| `bgm-home.mp3` | 첫 화면, 대기실 | 반복 |
| `bgm-game.mp3` | 게임 화면 | 반복 |
| `bgm-election.mp3` | 개표 결과 창(재보궐·총선) | 반복 |
| `bgm-ending.mp3` | 게임이 끝난 결과 화면 | 한 번 |

- 음량은 35%로 튼다. 곡 자체를 너무 크게 만들지 않는 편이 좋다.
- 브라우저는 사용자가 한 번 누르기 전에는 소리를 막으므로, 첫 클릭부터 나온다.
- 스팀판에 넣을 곡은 상업적 이용이 허락된 곡이어야 한다(`PHOTOS.md`와 같은 기준으로 출처를 남긴다).
- 다른 형식(ogg 등)을 쓰려면 `index.html`의 `BGM` 표에서 파일 이름을 바꾼다.

## 효과음 (코드로 만듦)

파일 없이 Web Audio로 그 자리에서 만든다(`index.html`의 `SFX`). 저작권 문제가 없다.

| 이름 | 나오는 때 |
|---|---|
| `click` | 표결·행동·사건 대응 등을 고를 때 |
| `stamp` | 기표하고 제출할 때, 개표가 끝나 도장이 찍힐 때 |
| `gavel` | 분기가 넘어가며 가결된 법이 있을 때 |
| `event` | 새 분기 사건이 공개될 때 |
| `tick` | 개표 중 의석이 켜질 때 |
| `reveal` | 개표 완료 |
| `win` / `lose` | 게임이 끝났을 때 우리 당 승패 |

효과음과 음악은 첫 화면·게임 화면의 '효과음'·'음악' 단추로 따로 끄고 켠다(이 브라우저에만 저장).
