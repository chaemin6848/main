일본국헌법의 3원칙과 기본적 인권

3원칙 = 국민주권 · 기본적 인권의 존중 · 평화주의(9조: 전쟁 포기, 전력 불보유, 교전권 부인). 1946년 11월 3일 공포, 1947년 5월 3일 시행.

정치

법의 지배와 법치주의

  • 법의 지배(영미) = 권력자도 법에 구속, '사람의 지배'의 반대. 법의 내용이 인권을 보장하는 올바른 것이어야 한다.
  • 형식적 법치주의(19세기 독일) = 법률에 근거한다는 형식을 중시, 법 내용의 정당성은 묻지 않음.
  • 흐름: 마그나 카르타(1215) → 코크가 브랙턴 '국왕은 누구 아래에도 있지 않으나 신과 법 아래에 있다'를 인용 → 권리청원(1628).

함정 코먼로 우위를 주장한 것은 코크, 필머는 왕권신수설. 보댕은 군주 주권을 옹호.

정치

재판소와 위헌심사

  • 하급재판소 = 고등(8곳)·지방·가정·간이. 특별재판소(행정재판소 등) 설치 금지 (76조). 지재고재는 도쿄고재의 특별지부.
  • 3심제: 1심 → 공소 → 상고. 최고재 장관은 내각 지명·천황 임명, 기타 재판관은 내각 임명.
  • 국민심사: 최고재 재판관은 임명 후 첫 중의원 총선 때 심사. 탄핵재판소는 국회에 설치.
  • 위헌심사권은 모든 재판소가 가짐(81조), 최고재가 종심 = '헌법의 수호자'. 구체적 사건에 부수해 판단하는 부수적 심사제.
  • 재판원제도(2009): 중대 형사사건 1심, 시민 6명 + 재판관 3명이 사실인정과 양형.

이문화 이해

  • 에스노센트리즘(자민족중심주의) = 자문화를 절대시해 다른 문화를 판단.
  • 문화상대주의 = 문화마다 고유의 가치, 우열 없음.
  • 다문화주의 = 여러 문화가 서로 존중하며 공존(동화주의의 반대).
  • 오리엔탈리즘 = 사이드가 비판한 서양의 편견적 동양관.
