# 제1당 엔진 도구

게임 규칙·선거·AI·승점은 `public/jeildang/engine.js` 한 파일에 있다. DOM에 의존하지 않아서
브라우저(`index.html`이 `<script src="engine.js">`로 읽음)와 Node에서 똑같이 돈다.

## 엔진 검사

```bash
node --test tools/jeildang/engine.test.js
```

- 같은 시드면 같은 판이 나오는지(멀티 재현성)
- 모든 모드·분기 수·정당 수에서 판이 끝나는지, 의석 합이 맞는지, NaN이 생기지 않는지
- 끝난 판 이어 하기

## AI 자동 대전 시뮬레이터

모든 정당을 AI가 두게 하고 노선·규모·정당별 승률과 승점 구성을 집계한다. 판당 약 10ms.

```bash
node tools/jeildang/sim.js --games 400 --country all
node tools/jeildang/sim.js --games 300 --country uk --set PTS.govLaw=0,PTS.ideoHit=1
```

| 옵션 | 뜻 |
|---|---|
| `--games` | 모드마다 돌릴 판 수 (기본 200) |
| `--rounds` | 분기 수 (기본 12) |
| `--size` | 가상 공화국 정당 수 (기본 5) |
| `--country` | `none`(가상 공화국) · `kr` · `jp` · `us` · `uk` · `fr` · `all` |
| `--set` | 엔진을 고치지 않고 `PTS`/`BAL` 값을 바꿔 실험 |
| `--continue` | 판이 끝나면 '한 임기 더 하기'로 N번 이어 간다 |
| `--json` | 집계를 JSON으로 출력 |

## AI 성격과 사건 (2026-11)

- **AI 성격**: AI 정당마다 `engine.js`의 `PERSONAS` 가운데 하나가 붙는다(원칙주의·포퓰리스트·협상가·강경파·실리형).
  행동 비율(`act`), 한 행동에 쓰는 돈(`spend`), 법안 발의 확률(`propose`), 연맹 제안 호감(`deal`·`line`), 먼저 제안하는 정도(`ask`)와
  표결 습관(`botVote`)이 다르다. 사람 당과 성격 도입 전에 만든 판의 AI는 예전 방식 그대로 둔다.
- **사건**: `EVENTS2`·`RESP`. 분기 초에 `g.event`로 공개되고, 각 당은 수(`mv.react`)에 대응 하나를 담는다.
  `follow`가 있는 사건은 정부 수반 당이 `unless` 대응을 고르지 않으면 다음 분기 사건으로 번진다. `target` 사건은 한 정당을 겨냥한다.
- 가상 공화국 AI끼리 800판 승률(공정 기준 20%, 사람 자리는 옛 AI): 협상가 27~31% · 원칙주의 25~32% · 실리형 23~27% · 포퓰리스트 20~21% · 강경파 14~15%.
  강경파는 공격에 우리 신뢰도 깎이는 위험을 지는 성격이라 일부러 조금 약하게 둔다.

## 콘텐츠와 사건 강화 (2026-11, 2차)

- 법안 56개, 사건 67개. 새 법안·사건은 `tools/jeildang/content_add.py`에 한·일·영으로 함께 적고 실행하면 engine.js와 번역표에 같이 들어간다.
- 사건 종류: 일반, 조건부(`when`: 여당 신뢰 바닥·총선 분기·분당 위기·돌풍·장기 집권, 분기마다 30% 확률), 나라 전용(`country`),
  지역(`region`·`reco`·`rsoc`·`ramt`: 그 권역 기반을 노선에 따라 움직임), 긴급 법안(`bill`: 그 분기 본회의에 오름), 번짐(`follow`)과 갈래(`branch`).
- 12분기 판 360개 기준: 일반 75% · 조건부 11% · 나라 전용 9% · 번진 사건 5%.
- 시나리오 6개(`SCENARIOS`, `scenarioState`). 목표는 성격 AI가 우리 당을 둘 때 성공률 9~32%가 되도록 맞췄다(사람이 더 잘 두는 것을 감안).

## 국가 모드 정당별 목표

실제 정당은 출발점이 너무 달라 승점 절대값으로 겨루면 여당이 거의 늘 이긴다(아래 '보정 전').
그래서 국가 모드는 정당마다 두 값을 준다.

- **목표 의석**: 마지막 총선 뒤 이만큼 이상이면 승점 +`PTS.goalHit`(10). AI끼리 둘 때 그 당의 최종 의석 중앙값이라, 평범하게 하면 절반쯤 달성한다.
- **기준 승점**: 순위는 `승점 − 기준 승점`(목표 대비)으로 매긴다. 모든 당의 목표 대비 1위 비율이 같아지도록 맞춘 값이다.

값은 `engine.js`의 `GOALS` 표에 6·12·18·24분기(`GOAL_ROUNDS`)별로 있고, 사이는 직선으로 잇는다.
표에 없는 당(새로 창당한 당)은 시작 의석이 가까운 두 당 값으로 보간한다. 가상 공화국은 예전처럼 승점 순위다.

규칙·배점·AI를 바꾸면 다시 맞춘다(약 5분). 그다음 보정에 쓰지 않은 시드로 확인한다.

```bash
node tools/jeildang/calibrate.js --games 1200
node tools/jeildang/sim.js --games 400 --country all
node tools/jeildang/sim.js --games 300 --continue 1 --country jp
```
